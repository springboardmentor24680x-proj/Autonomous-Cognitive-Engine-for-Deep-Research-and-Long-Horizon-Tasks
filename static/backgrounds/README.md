# Background Images

Place your background images in this folder and reference them in the CSS.

## Usage Examples:

1. **Local Image**: 
   ```css
   background: url('/static/backgrounds/your-image.jpg') center/cover no-repeat;
   ```

2. **Online Image**:
   ```css
   background: url('https://your-image-url.jpg') center/cover no-repeat;
   ```

## Supported Formats:
- JPG/JPEG
- PNG
- WebP
- SVG

## Recommended Size:
- Minimum: 1920x1080 (Full HD)
- Optimal: 2560x1440 (2K) or higher
- Keep file size under 2MB for fast loading
